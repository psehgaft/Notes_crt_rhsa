# Notes_crt_rhsa — RHCSA (EX200) Certification Study Notes

Personal study notes for the **Red Hat Certified System Administrator** exam (EX200).

## About

Notes collected while preparing for the RHCSA certification, focused on the
practical system administration skills the exam tests on Red Hat Enterprise Linux.

## Contents

The notes cover the main RHCSA objectives:

- Operate running systems: systemd services and targets, boot process troubleshooting
- Configure local storage: partitions, LVM, swap and file systems
- Create and configure file systems and file system attributes (permissions, ACLs, SELinux contexts)
- Deploy, configure and maintain systems: software management, kernel tuning
- Manage users and groups, including centralized authentication concepts
- Manage security: SELinux, firewalld, SSH hardening
- Manage containers: basic container lifecycle on RHEL

## How to use

These are reference notes — read them alongside a RHEL lab or virtual machine
while practicing each objective. Commands assume Red Hat Enterprise Linux 8/9.
